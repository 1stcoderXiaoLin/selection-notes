# Selection Notes（选中批注）

选中文字，右键添加批注，再把整个项目的原文与批注一次复制。

适用于代码审查、文档校对和把修改意见整理给协作者。支持 VS Code 1.100 及以上版本。

## 使用

1. 在主编辑区选中文字，右键选择 **Selection Notes: 添加批注**，选中内容下方会展开批注框。默认不会因选择文字自动弹出。
2. 输入批注，可写多行，点击 **保存**；成功后自动收起。点击 **取消** 关闭输入框，草稿不会保存，已有批注保留。
3. 在编辑器中右键选择 **Selection Notes: 复制项目全部批注**，或点击编辑器右上角的复制按钮。
4. 要删除某一条批注，展开后点击该条旁的垃圾桶按钮，直接删除这一条；同一选区的其他批注保留。
5. 要删除整个项目的批注，右键选择 **Selection Notes: 清空项目全部批注**，检查工作区和数量后，点击 **清空全部批注**。取消确认不会删除数据。

添加、复制和清空命令也可以通过命令面板搜索 `Selection Notes` 执行。即使当前文件没有批注，也可以从这里汇总整个工作区。

支持代码、Markdown、TXT、JSON、日志、无标题文本及可以在 VS Code 文本编辑器中选择的只读文档。输出面板、调试控制台、终端和批注输入框不提供批注。不处理 PDF、Word 或图片预览。多个光标同时选择时只处理主选区。查找跳转、恢复光标等程序定位不自动创建批注。

## 设置

设置中搜索 **Selection Notes**：

- **触发方式** `selectionNotes.triggerMode`：默认 `contextMenu`，通过右键添加；改为 `automatic` 后，鼠标、键盘选区稳定时自动弹出。
- **弹框等待时长** `selectionNotes.popupDelay`：仅影响自动模式，单位为毫秒，默认 `200`，允许 `0`。

配置修改后立即对新选区生效。自动模式从最后一次选区变化开始计时，持续拖选会重置等待；VS Code 公开 API 不提供鼠标松开事件，因此按住鼠标暂停超过等待时长仍可能弹出。希望完全避免打断拖选，请保留默认右键模式。

批注框采用 VS Code 原生行内样式，尺寸与主题由编辑器控制，无法设置为固定宽度的悬浮窗。标题和提示保持简洁，保存成功后通过状态栏短暂提示；保存失败则保留输入框并提示原因。

## 从旧测试包更新

本版通过按钮保存、取消批注，不注册快捷键，不改动 VS Code 或其他扩展自身的按键行为。

如果此前手动添加过本插件的用户快捷键，请在“首选项: 打开键盘快捷方式(JSON)”中删除 `selectionNotes.saveFocusedComment`、`selectionNotes.cancelFocusedComment`，以及为本插件单独添加的 `workbench.action.hideComment` 绑定；只删除此前追加的条目，保留其他配置。

## 复制结果

```text
文件：src/example.ts
原始行号：12–14
原文：
用户当时选中的内容

批注：
这里需要补充参数校验。

----------------------------------------
```

只选中一个变量名，原文就只包含这个变量名，不会扩展成整行。缩进、空格和换行保留原样。结果按文件路径、原始位置、创建顺序排列，没有批注时不覆盖已有剪贴板。

项目内显示相对路径；工作区包含多个文件夹时附带文件夹名称；项目外的文档使用路径或 URI。

## 保存与原文变化

- 批注保存在 VS Code 当前工作区的 `workspaceState`，关闭并重开同一工作区仍可使用。不会在源文件中插入注释，也不会向项目写入批注文件。
- 工作区包含多个根目录时一起汇总；没有打开文件夹时，以当前空窗口的工作区为范围。换一个工作区文件，即使它包含相同目录，数据也是独立的。
- 批注保存的是选中文字时的原文和行号。之后修改、重命名或删除原文件，复制仍使用旧快照，不会悄悄改成最新代码。
- 原位置的文字与快照不再一致时，批注会标记为文件级历史批注，不猜测新位置。即使原文件不存在，也能通过复制命令拿到快照。
- 未提交的草稿不会持久化，也不会进入复制结果。关闭窗口或确认清空会丢弃草稿。
- 扩展不上传批注，不调用网络服务，也不提供跨设备同步。清空只针对当前工作区。

## 安装本地包

在 VS Code 的扩展视图右上角选择 **从 VSIX 安装…**，打开 `selection-notes-0.1.1.vsix`。按编辑器提示重新加载窗口后即可使用。

当前源码中的 `selection-notes-local` 是本地安装用的发布者占位标识，不代表已经上架。

## 开发

需要 Node.js 20.19 或更新版本，以及 npm。

```sh
npm ci
npm run check
npm run test:unit
npm run build
npm run package
```

使用 VS Code 打开项目，按 F5 运行“运行 Selection Notes”，在新出现的扩展开发窗口中选中文字体验。

真实扩展宿主测试会下载 VS Code 1.100.3，连续启动三次，检查正常使用、重启恢复和工作区隔离：

```sh
npm run test:integration
```

无桌面的 Linux 需要虚拟显示环境：

```sh
xvfb-run -a npm run test:integration
```

也可通过 `VSCODE_EXECUTABLE_PATH` 指定已经安装的 VS Code 可执行文件，避免下载。测试使用临时工作区、用户数据目录和扩展目录，不操作日常工作区的批注。
